Pointfix privacy policy

Last updated: 23 October 2026

What Pointfix does

When you click the toolbar icon, Pointfix lets you select an element on the current page and send a request about it to a coding agent (Claude Code or OpenAI Codex) that you have installed and signed in to on your own computer.

Data Pointfix handles

When you press Send or Copy prompt, Pointfix collects, from the current tab only:

  • the page address (URL)
  • the selected elements' HTML, visible text, CSS selector, size, position and a few computed styles
  • the name of the UI component and its source-file location, when the page is a development build that exposes it
  • a screenshot of each selected element
  • the viewport size, and, if you leave "Include page errors" checked, uncaught JavaScript errors and the addresses of failed requests on the page
  • the message you typed and the project folder path you chose

Nothing is collected until you open the picker on a tab, and nothing is sent until you press Send.

Where the data goes

This data is passed to a helper program on your computer, which you install yourself (npx pointfix install). The helper hands it to the Claude Code or Codex command-line tool you chose. That tool then sends it to its provider, Anthropic or OpenAI, under your own account and that provider's terms and privacy policy:

  • Anthropic: anthropic.com/legal/privacy
  • OpenAI: openai.com/policies/privacy-policy

The developer of Pointfix runs no servers and receives none of this data. Pointfix contains no analytics, tracking or advertising, and the data is never sold or shared with anyone else.

Data stored on your device

Pointfix saves, in Chrome's local extension storage on your computer:

  • the project folder for each website, your chosen agent and mode, and the panel position
  • conversation IDs, so follow-up messages continue the same conversation
  • your last 20 chats per site (your messages, the agent's replies and the change lists, without screenshots), so you can reopen them

Screenshots are written to a temporary file for the agent to read and deleted when the request finishes. To show and undo changes, the helper records snapshots of your project folder with git: inside your repository's own object store for git projects, or in ~/.pointfix/snapshots/ for other folders. These never leave your computer.

Removing the extension deletes its stored data. Running npx pointfix uninstall removes the helper and its snapshots.

Permissions

  • activeTab, scripting: run the element picker on the current tab, only after you click the toolbar icon or press the shortcut
  • nativeMessaging: talk to the helper program on your computer
  • storage: remember the settings and chats listed above
